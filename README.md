# 📊 Unemployment Analysis with Python
### CodeAlpha Data Science Internship — Task 2

## 📌 Project Overview

This project performs a comprehensive analysis of **Unemployment in India** using Python. It explores unemployment trends over time, investigates the **impact of Covid-19** on unemployment rates, compares **Urban vs Rural** unemployment, and identifies **regional disparities** across Indian states.

This is **Task 2** of the CodeAlpha Data Science Internship Program.

---

## 🎯 Objectives

- Analyze unemployment rate data across Indian regions
- Investigate the impact of **Covid-19** on unemployment
- Compare **Urban vs Rural** unemployment trends
- Identify key patterns and seasonal trends
- Present insights that could inform economic or social policies

---

## 📁 Dataset

- **Source:** Unemployment in India Dataset
- **Records:** 768 rows × 7 columns
- **Date Range:** May 2019 — October 2020

| Column | Description |
|--------|-------------|
| Region | Indian state/region |
| Date | Month of record |
| Frequency | Monthly data |
| Estimated Unemployment Rate (%) | Unemployment percentage |
| Estimated Employed | Number of employed people |
| Estimated Labour Participation Rate (%) | Labour participation rate |
| Area | Rural or Urban |

---

## 🔍 Key Findings

- **Covid-19** caused a sharp spike in unemployment across India in March–June 2020
- **Urban areas** experienced higher unemployment than rural areas
- **Tripura** recorded the highest average unemployment rate
- Significant **regional disparities** exist across Indian states
- Unemployment showed a gradual recovery after the lockdown period
